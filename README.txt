部署方法

仓库结构必须是：

nanmo/
├── index.html
└── nmo/
    ├── IMG_9184.MP4
    ├── IMG_9192.MP4
    ├── ...
    └── photo_....jpg

把本压缩包中的 index.html 上传到仓库根目录即可。
不要放进 nmo 文件夹。

如果 GitHub Pages 已从 main / root 部署：
https://ff813ff.github.io/nanmo/
https://ff813ff.github.io/nanmo/?chan=ALL

都会打开同一个媒体列表。

当前 index.html 已写入：
11 个 MP4
28 张 JPG
总计 39 个媒体坑位。
